# Alex

I build [Myrmidon](https://github.com/itkadr-git/myrmidon) — an orchestration platform for AI agents.

At some point the existing tools stopped being enough, so I built my own. Myrmidon takes its inspiration from the μυρμηδόνες — the mythic people turned into ants. A real ant colony has no manager: the work organizes itself through marks left in a shared environment, not through orders. That's the model I want for AI agents — a colony coordinated by signals, not micromanagement.

# Alex

Я делаю [Myrmidon](https://github.com/itkadr-git/myrmidon) — систему управления командой ИИ-агентов на своём сервере.

Мне стало мало существующих инструментов, и я сделал свой. Меня вдохновили мирмидоняне (греч. μυρμηδόνες) — мифические люди-муравьи. В муравейнике нет управляющего: работа налаживается сама, по меткам, оставленным в общей среде, а не по приказам. Для ИИ-агентов нужна та же модель: колония, которой управляют сигналы, а не мелочный контроль.
