## Myrmidon — an orchestration platform for AI agents

**The idea.** Myrmidon is named after the μυρμηδόνες, the mythic people turned into ants. Real ants run a colony with no manager: work gets coordinated through marks left in a shared environment, a division of labor between castes, and a continuous balance of the colony's energy. Myrmidon grows toward the same model for AI agents — an organization coordinated by signals in the environment, not by micromanagement. When idle, the colony forages for knowledge. Its memory outlives any single agent. The core stays thin, and anything that crosses the autonomy line still goes through a human.

**What it is today:** a self-hosted task board where a fleet of AI agents picks up work, runs it in isolated containers with its own model, keys, and memory, reports back — and asks a human only when a decision needs one.

**For whom:** teams who run AI agents as permanent staff, with budgets, review gates, and safe deploys, on their own server.

## Myrmidon — система управления командой ИИ-агентов на своём сервере

**Идея.** Myrmidon назван в честь мирмидонян (греч. μυρμηδόνες) — мифических людей-муравьёв. Настоящий муравейник обходится без управляющего: работа налаживается сама через метки, оставленные в общей среде, разделение труда между кастами и непрерывную балансировку вычислительной энергии колонии. Myrmidon идёт к той же модели для ИИ-агентов — организации, где работой управляют сигналы в среде, а не микроменеджмент. В простое колония накапливает знания; её память переживает любого отдельного агента; ядро остаётся тонким, а всё, что выходит за черту автономии, по-прежнему проходит через человека.

**Что это сегодня:** доска задач на своём сервере, где ИИ-агенты разбирают задачи, выполняют их в изолированных контейнерах — со своей моделью, ключами и памятью, — отчитываются и спрашивают человека только там, где нужно решение.

**Для кого:** для команд, которые работают с ИИ-агентами как с постоянным штатом — с бюджетами, проверками и безопасным выкатом, на своём сервере.
